X16 STORE — متجر بوتات ديسكورد (نسخة الطلبات إلى ديسكورد)
=======================================================

ما الجديد؟
- عند ضغط العميل على «متابعة وتأكيد الطلب» تظهر نافذة لتسجيل الاسم واسم ديسكورد أو User ID.
- عند التأكيد يرسل الموقع تفاصيل الطلب إلى روم ديسكورد عبر Webhook.
- تفاصيل رسالة الطلب: رقم الطلب، اسم العميل، وسيلة التواصل، المنتجات، الأسعار المعروضة، الملاحظات، وحالة «بانتظار المراجعة».
- بعد نجاح الإرسال تظهر للعميل رسالة «تم استلام طلبك وسيتم مراجعته» ورابط دعوة سيرفر الديسكورد.
- لا يتم إظهار النجاح إذا فشل الإرسال إلى ديسكورد.
- تمت إضافة حد مبدئي لمحاولات إرسال الطلبات لمنع الإغراق.

المتطلبات:
- Node.js 20 أو أحدث.
- سيرفر أو استضافة تدعم تشغيل Node.js باستمرار. الاستضافة الثابتة فقط (Static Hosting) لا تشغّل server.js.

إعداد استقبال الطلبات في ديسكورد:
1) افتح روم الطلبات في سيرفر ديسكورد.
2) ادخل Edit Channel / تعديل القناة.
3) افتح Integrations / التكاملات ثم Webhooks.
4) اختر New Webhook، وسمّه مثلًا X16 Store Orders، وحدد الروم الصحيح.
5) انسخ Webhook URL. لا تنشره ولا ترسله لأحد؛ اعتبره كلمة مرور لإرسال الرسائل إلى الروم.

إعداد رابط الدعوة:
1) أنشئ رابط دعوة لسيرفر المتجر من ديسكورد.
2) اجعله صالحًا حسب احتياجك، ثم انسخ الرابط.

تشغيل الموقع محليًا على Windows:
1) فك ضغط الملف.
2) افتح CMD داخل مجلد x16-discord-bots-store.
3) أنشئ ملف الإعدادات:
   copy .env.example .env
4) افتح .env بالمفكرة وضع القيم التالية:
   DISCORD_WEBHOOK_URL=رابط_Webhook_الذي_نسخته
   DISCORD_INVITE_URL=رابط_دعوة_سيرفرك
   PORT=3000
5) احفظ الملف.
6) ثبّت المكتبات:
   npm install
7) شغّل الموقع والخادم:
   npm start
8) افتح المتصفح على:
   http://localhost:3000

شكل الطلب في روم ديسكورد:
- عنوان: طلب جديد — X16 STORE
- رقم الطلب.
- اسم صاحب الطلب.
- اسم ديسكورد أو User ID الذي أدخله العميل.
- أسماء المنتجات المطلوبة.
- ملاحظات العميل.
- الحالة: بانتظار مراجعة فريق المتجر.

تعديل المنتجات والأسعار:
- افتح app.js.
- عدّل STORE_CONFIG ثم products.
- كل منتج يحتوي على id وname وcategory وdescription وfeatures وprice.
- لا تضع أسرارًا أو توكنات داخل app.js؛ هذا الملف يصل إلى زوار الموقع.

النشر على استضافة:
- ارفع المشروع كاملًا إلى استضافة تدعم Node.js (وليس Static Site فقط).
- اجعل أمر التشغيل Start Command هو: npm start
- أضف DISCORD_WEBHOOK_URL وDISCORD_INVITE_URL كـ Environment Variables من لوحة الاستضافة.
- لا ترفع ملف .env إلى GitHub أو إلى مجلد عام. ملف .gitignore يستثنيه.
- تأكد أن الاستضافة تسمح بطلبات HTTPS الصادرة إلى discord.com.

الأمان والخصوصية:
- يستخدم المشروع Discord Webhook من جهة الخادم؛ لا يظهر رابط Webhook في كود المتصفح.
- لا يحتاج إلى توكن بوت ديسكورد.
- لا ينفذ الموقع أي دفع إلكتروني. إرسال الطلب هو طلب مراجعة فقط.
- بيانات النموذج ترسل إلى روم الطلبات في سيرفرك. أخبر العملاء بذلك عند الحاجة.
- عند تسريب Webhook URL، احذفه وأنشئ Webhook جديدًا.
- لا تضع مفاتيح أو بيانات سرية في ملفات public أو app.js.

ملاحظة:
هذه النسخة لا تحتوي على قاعدة بيانات للطلبات أو لوحة إدارة. سجل الطلبات الأساسي محفوظ في روم ديسكورد عبر رسائل Webhook.
